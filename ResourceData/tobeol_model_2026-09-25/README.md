# 길드 토벌전 예측 모델

2026-09-25 MGF 공개 기록 12,041명으로 적합한 전직 구간 검토 버전이다.
레벨·전투력으로 공개 토벌전 기록을 추정하며, 현재 선택된 모델의 직업 배수는 모두 1이다.
정확한 계수·학습 범위·검증 결과·직업별 표본 수는 `model.json`에 보존했다.

- 입력 전투력: 원 단위. **1경 = 10^16**. 기존 리포트의 `combat_power_value`는 만 단위이므로 변환이 필요하다.
- 출력 점수: 원 단위. `score_jo`는 조 단위다.
- 전직 구간: 10·30·70·100레벨. 30레벨 미만은 학습 표본이 없어 예측하지 않는다.
- 학습 7,835명 / 구간 보정 1,836명 / 검증 2,370명.
- 같은 검증 세트를 다시 평가한 상대오차 중앙값 18.49%, ±30% 이내 72.32%.
- 기록 당시 장비·전직 완료 여부는 확인되지 않으며, 미래 시즌 검증은 하지 않았다.

`mgf_guild_export.py`는 같은 길드 페이지에서 공개된 실제 점수와 능력치로 비교한다.
미공개 멤버를 0점으로 취급하지 않으며 합계는 실제·예측 모두 있는 동일 멤버만 포함한다.
길드 페이지 자료를 쓸 때 순위는 공개 멤버 내 실제 점수 순서다.

저장한 원자료로 두 토벌전 페이지를 네트워크 조회 없이 다시 생성할 수 있다.

```sh
.venv/bin/python mgf_guild_export.py --guild-name 빅딜 --tobeol-source reports/빅딜/tobeol_source.json
.venv/bin/python mgf_guild_export.py --guild-name 셀린느 --tobeol-source reports/셀린느/tobeol_source.json
```
